# Sound credits

Every sound in this folder is a real recording, cut and levelled by
`tools/audio/build_sounds.py`, which records exactly how each file was made.
File names are sound ids (see `scripts/audio/sound_bank.gd`);
`name_1.ogg`, `name_2.ogg`, … are random variations of the same sound.

All sources are from [Freesound](https://freesound.org). All are CC0 (public
domain, no attribution required) **except one, which requires attribution**:

> **"biking padelling 160317_00.wav" by klankbeeld**, https://freesound.org/s/340737/ ,
> licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
> Used (cut, looped, level-adjusted) in `riding/tyre_loop.ogg`.
